# ARCHIVOS_Y_PLANTILLAS.md

## Estado de carga

Este repositorio contiene versiones textuales, buscables y versionadas de las plantillas y documentos base entregados al proyecto.

Estas versiones permiten:
- localizar secciones por nombre;
- reutilizar estructura y terminología;
- comparar metodologías;
- construir nuevos informes a partir de la fuente oficial.

## Importante sobre formato

Las versiones Markdown son extracciones fieles del contenido textual y están pensadas para ser leídas directamente por el asistente desde GitHub.

Los archivos originales DOCX/PDF contienen el formato visual de referencia —estilos, tablas, paginación y diagramación—. La extracción Markdown no sustituye ese formato visual.

Cuando se necesite replicar diseño visual exacto, debe utilizarse el archivo binario original correspondiente como referencia adicional.

## Regla de precedencia

Para contenido y estructura:
1. plantilla vigente en `/plantillas`;
2. contexto metodológico de raíz;
3. memoria histórica.

Para estilo visual exacto:
1. archivo DOCX/PDF original;
2. versión Markdown como apoyo textual.
