# Informes UAI — Contexto, plantillas y referencias

Repositorio maestro para la investigación y diseño de experiencia de programas UAI.

Este repositorio centraliza:
- archivos de contexto y memoria del proyecto;
- reglas metodológicas para análisis cualitativo;
- plantillas oficiales de informes;
- documentos de referencia;
- estructuras para Journey y Service Blueprint.

## Orden de lectura recomendado

Antes de elaborar cualquier informe:

1. `AGENTS.md`
2. `memory.md`
3. `ROLES_Y_FUENTES.md`
4. `CONTEXTO_REPORTES.md`
5. `PLANTILLAS_Y_FLUJO.md`
6. La plantilla específica solicitada
7. Las fuentes primarias del programa

## Principio central

La unidad de análisis es la experiencia reportada a lo largo del Journey.

**Qué vive el estudiante → por qué ocurre → qué sistema lo produce → qué oportunidad de diseño existe.**

## Estructura

- `/plantillas`: plantillas reutilizables de informes.
- `/referencias`: documentos de apoyo, hallazgos y Service Blueprint.
- raíz: contexto, memoria, roles, metodología y estado del proyecto.

## Regla de evidencia

Nunca completar vacíos con supuestos. Distinguir siempre:
- evidencia directa;
- interpretación;
- hipótesis;
- propuesta de diseño;
- información pendiente de validar.

La plantilla vigente del repositorio prevalece sobre estructuras históricas descritas en memoria.
