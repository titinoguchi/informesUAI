## Alcance
Ocho programas: DAE, DDS, DEA, DF, DIIIO, DNSC, DPIP y DISC. Se integran las perspectivas de estudiantes/egresados, direcciones, coordinaciones y áreas de apoyo. La arquitectura transversal utiliza siete etapas, preservando particularidades de cada doctorado.

## Principio rector
